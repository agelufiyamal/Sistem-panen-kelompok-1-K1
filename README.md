# Sistem Pencatat Hasil Panen Digital

## Deskripsi

Sistem Pencatat Hasil Panen Digital adalah program sederhana yang dibuat menggunakan Python. Program ini digunakan untuk mencatat data hasil panen berdasarkan nama petani atau blok lahan, berat panen, dan kadar air.

Program ini juga dapat menampilkan laporan hasil panen serta menghitung harga, diskon, dan total pembayaran.

## Fitur

- Input data hasil panen
- Menampilkan laporan hasil panen
- Menghitung total berat panen
- Menghitung rata-rata kadar air
- Menghitung harga hasil panen
- Menghitung diskon dan total pembayaran

## Struktur Program

- `input.py` untuk memasukkan data hasil panen
- `laporan.py` untuk menampilkan laporan hasil panen
- `diskon.py` untuk menghitung diskon dan total pembayaran
- `main.py` untuk menjalankan program utama

## Cara Menjalankan Program

1. Pastikan Python sudah terpasang di komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka terminal pada folder proyek.
4. Jalankan perintah berikut:

```bash
python main.py
